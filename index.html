3 Cara Membungkus Repositori GitHub Jadi APK Android
1 Metode PWABuilder (Paling Cepat & Gratis Tanpa Coding) Rekomendasi

1. Deploy repositori GitHub Anda ke GitHub Pages atau Vercel / Netlify.
2. Buka web https://www.pwabuilder.com di browser laptop/HP.
3. Masukkan link website Anda dan klik Start.
4. Klik tombol Package for Android → Pilih Generate APK.
5. File APK siap langsung dipasang di HP Android tanpa perlu Android Studio!

2 Metode GitHub Actions Otomatis (.github/workflows/build-apk.yml)

1. File alur kerja .github/workflows/build-apk.yml sudah tersimpan di dalam repositori ini.
2. Setiap kali Anda melakukan git push ke GitHub, GitHub Actions otomatis menguji dan mem-build paket distribusi.
3. Anda dapat mengunduh hasil bundel web langsung dari tab Actions → Artifacts di halaman repositori GitHub Anda.

3 Metode WebIntoApp / AppsGeyser WebView

1. Buka webintoapp.com atau appsgeyser.com.
2. Pilih menu "Create App from Website" dan masukkan URL hasil deploy GitHub.
3. Beri nama PM X BL dan unggah ikon dari folder /public/pwa-512x512.png.
4. Unduh APK yang sudah jadi langsung ke smartphone Anda.

Panduan Kompatibilitas Khusus APK AppsGeyser & Android WebView

Aplikasi ini dirancang sebagai Single File HTML Standalone yang 100% kompatibel saat dikompilasi menjadi aplikasi APK Android melalui AppsGeyser maupun browser WebView native.

1. Solusi Kamera HP: 2 Tombol Terpisah

Beberapa Android WebView membatasi akses input file biasa. Oleh karena itu, kami menyediakan 2 tombol khusus:
• "Foto Kamera Belakang": Menggunakan parameter capture="environment" untuk membuka sensor kamera hardware HP Android secara langsung.
• "Pilih dari Galeri HP": Fallback aman jika ingin mengunggah foto nota atau faktur yang sudah tersimpan di galeri.

2. Pengaturan Izin AndroidManifest di AppsGeyser

Pada dashboard AppsGeyser (bagian Edit > Custom Permissions), pastikan izin berikut diaktifkan agar kamera dan penyimpanan lokal berjalan normal:

<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
3. Cetak Struk ke Printer Thermal Bluetooth HP

Saat menekan tombol PROSES TRANSAKSI & CETAK STRUK, dialog cetak bawaan HP Android akan terbuka otomatis. Format lebar kertas telah diatur presisi untuk kertas struk kasir mini 58mm atau 80mm.
